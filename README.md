This repository is a learning-focused project for exploring Retrieval-Augmented Generation (RAG) concepts through hands-on practice.

## Purpose

The goal of this repo is to learn by doing. It covers the core ideas behind RAG, from preparing documents and chunking data to retrieval, reranking, and evaluation.

## What this repository includes

- Document preparation and indexing
- Chunking strategies
- Embedding and retrieval workflows
- Hybrid and similarity-based search
- Reranking techniques
- Evaluation of retrieval quality and answer quality
- Practical experiments for understanding advanced RAG patterns

## Why this exists

This project is intended as a study resource for understanding how modern AI systems use external context to generate more relevant and grounded answers.

## Notes

This is not a production application, but rather an educational repository for experimentation and learning.
